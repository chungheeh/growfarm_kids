# **키움밥상 (Growing Table)**

**작성자:** 2조 (양가윤, 강윤선, 한충희, 곽기명)

**프로젝트 기간:** 2025학년도 2학기

---

## **1. 프로젝트 개요 (Executive Summary)**

키움밥상은 아동급식카드를 사용하는 결식우려아동의 영양 관리와 성장 모니터링을 지원하는 웹 기반 플랫폼입니다. 현재 결식아동의 70% 이상이 편의점에서 끼니를 해결하며 영양 불균형 문제를 겪고 있습니다. 본 서비스는 아동의 식사 데이터를 분석하여 영양소 섭취 현황과 BMI 기반 성장 추이를 시각화하고, 보호자가 직관적으로 아동의 발달 상태를 관리할 수 있도록 지원합니다.

**핵심 가치:**

- 아동의 건강한 성장을 데이터 기반으로 지원
- 보호자의 편리한 모니터링 환경 제공
- 정책 입안을 위한 실질적 데이터 수집

---

## **2. 프로젝트 목표 및 필요성**

### **2.1 배경 및 문제 정의**

**현황:**

- 수도권 외 지역 결식아동의 대부분이 편의점에서 끼니 해결
- 지역별 편의점 의존도: 대전 72.8%, 대구 70.6%, 강원 62.8%
- 아동급식카드 가맹점 중 편의점 비중이 압도적으로 높음
- 영양 불균형으로 인한 성장 발달 저해 우려

**문제점:**

- 아동의 식사 선택권 제한
- 영양소 섭취 불균형 모니터링 부재
- 보호자의 아동 건강 상태 파악 어려움
- 지역별 급식 현황 데이터 부족

### **2.2 프로젝트 목표**

**Primary Goals:**

1. **아동 맞춤형 성장 지원**
    - 아동급식카드 식사 데이터 분석
    - 영양소 섭취 현황 시각화
    - BMI 기반 성장 추이 모니터링
2. **보호자 직관적 관리**
    - 아동의 발달 상태 실시간 확인
    - 식습관 균형 여부 파악
    - 부족한 영양소 정보 제공
3. **데이터 기반 정책 활용**
    - 지역별 아동 급식 현황 파악
    - 영양 불균형 문제 데이터화
    - 정책 개선을 위한 근거 자료 제공

## **4. 주요 기능 (Key Features)**

### **4.1 영양소 분석 기능**

**Description:**
아동의 식사 데이터를 기반으로 일일 영양소 섭취량을 계산하고, 연령별 권장 섭취 기준(DRI)과 비교하여 부족하거나 과다한 영양소를 분석합니다.

**Features:**

- 탄수화물, 단백질, 지방, 비타민, 미네랄 등 주요 영양소 추적
- 권장 섭취량 대비 실제 섭취량 비교
- 일별/주별/월별 영양소 섭취 추이 그래프
- 부족한 영양소 알림 및 개선 제안

**User Flow:**

1. 아동이 식사 정보 입력
2. 시스템이 영양성분 데이터 분석
3. 권장 섭취량과 비교
4. 시각화된 결과 제공
5. 부족한 영양소 정보 텍스트로 안내

**Success Metrics:**

- 영양소 분석 정확도 95% 이상
- 일일 활성 사용자의 70% 이상이 영양소 분석 기능 활용

### **4.2 BMI 분석 기능**

**Description:**
아동의 키와 체중 데이터를 활용해 BMI(체질량지수)를 산출하고, 소아청소년 성장 곡선 표준과 비교하여 발달 상태를 평가합니다.

**Features:**

- 연령별/성별 BMI 백분위수 계산
- 성장 곡선 그래프 (저체중/정상/과체중/비만 구간 표시)
- 월별 성장 추이 모니터링
- 또래 평균 대비 비교 (익명화된 데이터)

**User Flow:**

1. 보호자/아동이 키, 체중 입력
2. 생년월일 기반 연령 계산
3. BMI 및 백분위수 산출
4. 성장 곡선에 표시
5. 발달 상태 평가 결과 제공

**Success Metrics:**

- BMI 데이터 입력률 월 1회 이상 80%
- 성장 추이 확인률 주 1회 이상 60%

### **4.3 OCR 이미지 인식 기능**

**Description:**
NAVER CLOVA OCR API를 활용하여 식품 영양성분표를 촬영하면 자동으로 영양 정보를 인식하고 입력합니다.

**Features:**

- 영양성분표 사진 촬영
- 자동 텍스트 추출 (열량, 탄수화물, 단백질, 지방 등)
- 인식 결과 수정 기능
- 식사 기록에 자동 저장

**User Flow:**

1. 아동이 영양성분표 촬영
2. OCR API가 텍스트 추출
3. 영양소 데이터 파싱
4. 사용자 확인 후 저장
5. 식사 기록에 추가

**Success Metrics:**

- OCR 인식 정확도 90% 이상
- 수동 입력 대비 입력 시간 70% 단축
- OCR 기능 사용률 전체 식사 기록의 50% 이상

### **4.4 전국 가맹점 조회 기능**

**Description:**
카카오맵 API를 활용하여 전국의 아동급식카드 사용 가능 가맹점을 지도에 표시하고, 다양한 조건으로 필터링하여 검색할 수 있습니다.

**Features:**

- 현재 위치 기반 주변 가맹점 표시
- 지역별 가맹점 검색
- 업종별 필터링 (식당, 편의점, 카페 등)
- 가맹점 상세 정보 (주소, 전화번호, 영업시간)
- 즐겨찾기 기능

**User Flow:**

1. 사용자가 지도 화면 접근
2. 현재 위치 또는 검색 지역 선택
3. 필터 조건 설정 (업종, 거리 등)
4. 지도에 가맹점 마커 표시
5. 가맹점 선택 시 상세 정보 확인

**Success Metrics:**

- 가맹점 데이터베이스 커버리지 전국 95% 이상
- 지도 검색 기능 사용률 주 2회 이상 40%

**5. 가맹점 지도**

- 지도 뷰
- 필터 옵션
- 가맹점 리스트
- 상세 정보 팝업

**6. 마이페이지**

- 프로필 정보 수정
- 키/체중 업데이트
- 보호자 연결 관리

**7. 설정**

- 알림 설정
- 데이터 관리
- 로그아웃

## **8. 사용자 플로우 (User Flow)**

### **8.1 아동 사용자 플로우**

1. 회원가입 → 기본 정보 입력
2. 메인 대시보드 확인
3. 식사 후 식사 추가 (OCR 또는 수동)
4. 영양소 분석 결과 확인
5. 주기적으로 키/체중 업데이트
6. 가맹점 검색 및 식사 장소 선택

### **8.2 보호자 사용자 플로우**

1. 회원가입 → 아동 계정 연결
2. 아동의 식사 기록 모니터링
3. 영양소 섭취 및 BMI 추이 확인
4. 부족한 영양소 파악
5. 아동에게 식습관 개선 조언
